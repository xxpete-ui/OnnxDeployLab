## 本机环境

使用 VS2022 打开本目录，选择 x64-Debug，构建并运行 model_inspect。
CMake 默认沿用原项目依赖路径，可通过 ORT_ROOT 和 OpenCV_DIR 调整。

运行参数：
```text
model_inspect.exe <分类ONNX路径> <224x224图片路径>
```

不传参数时，使用代码中已确认的本机模型路径及学习图片路径。正式推理预处理仍需核对训练/导出约定。

模型目录：
- models/cls/：分类模型 hezhuang5.onnx
- models/seg/：分割模型，具体文件名待确认

模型、图片、DLL、构建输出默认忽略，不随代码提交。新机器需单独准备依赖与模型。
